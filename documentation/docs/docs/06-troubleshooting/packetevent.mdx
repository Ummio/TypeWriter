# PacketEvents 故障排除

如果在启用 Typewriter 插件时遇到与 `io.github.retrooper.packetevents` 相关的错误，如 `java.lang.NoClassDefFoundError`，这可能是由于 PacketEvents 插件版本不兼容导致的。

## 错误信息

你可能会看到类似这样的错误信息：

```bash
[12:41:54 ERROR]: 启用 Typewriter v0.5.1 时发生错误（是否已更新？）
java.lang.NoClassDefFoundError: io/github/retrooper/packetevents/bstats/Metrics$CustomChart
        at me.gabber235.typewriter.entry.entity.EntityHandler.initialize(EntityHandler.kt:23) ~[typewriter (5).jar:?]
        at me.gabber235.typewriter.Typewriter.onEnableAsync(Typewriter.kt:121) ~[typewriter (5).jar:?]
```

## 问题原因

这个错误发生是因为安装的 PacketEvents 版本与你正在使用的 Typewriter 版本不兼容。**Typewriter v0.5.1 需要 PacketEvents 2.5.x 版本。**使用更新版本的 PacketEvents 可能会因 API 变更导致兼容性问题。

### 解决步骤

1. **删除**服务器 `plugins` 文件夹中当前的 PacketEvents 插件。

2. **下载** PacketEvents **2.5.0** 版本，[点击此链接下载](https://modrinth.com/plugin/packetevents/version/QLgJReg5)。

3. **放置**下载的 PacketEvents jar 文件到服务器的 `plugins` 文件夹中。

4. **重启**服务器以应用更改。

## 验证修复

按照上述步骤操作后，Typewriter 插件应该能够正常加载。检查服务器日志，确认不再出现与 PacketEvents 相关的 `NoClassDefFoundError` 错误。
