本教程将教你如何让 TypeWriter 与 Playit.gg 配合使用。

## 什么是 Playit.gg
Playit.gg 是一个服务，可以让你的本地 Minecraft 服务器对外开放，供任何人连接。这对于与朋友测试服务器或短期开放公共服务器很有用。

## 如何让 TypeWriter 与 Playit.gg 配合使用
首先访问 [playit.gg](https://playit.gg/) 并创建一个代理，将你的 Minecraft 服务器连接上去。网上有很多关于如何做这件事的教程。

### 创建新隧道
在隧道标签页中，你可以点击 `+ 添加隧道`。

<Image img={require("../assets/troubleshooting/tunnels.png")} alt="隧道" />

然后在弹出窗口中选择你的地区，使用 `TCP (协议)` 作为隧道类型，将本地端口设置为 `8080`（或你在 config.yml 中配置的端口），然后点击 `添加隧道`。

<Image img={require("../assets/troubleshooting/create-tunnel.png")} alt="创建隧道" />

现在你的隧道应该处于等待状态，几秒钟后就会开始工作。

### 连接到 TW 面板
现在你可以使用隧道标签页中显示的 URL 来连接到面板。

<Image img={require("../assets/troubleshooting/ip.png")} alt="隧道 URL" />
