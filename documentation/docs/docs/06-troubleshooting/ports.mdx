# 面板加载问题故障排除指南

Typewriter 插件的面板无法加载？本指南将帮助你排除故障并确保正确设置以获得最佳功能。

## 正确分配端口

如果面板无法加载，常见的问题可能是缺少分配的端口。Typewriter 插件需要两个开放的端口：

1. 一个端口用于加载面板。
2. 另一个端口用于与服务器进行 websocket 通信。

:::warning
像 Aternos 这样只提供单个端口的托管平台，由于这个要求而无法与 Typewriter 插件兼容。
:::

## 使用正确的 URL

确保你使用正确的 URL 来访问面板。格式应该是 `ip:端口` 或者，如果你使用子域名，则是 `url:端口`。使用正确的 URL 对于成功访问面板至关重要。

## 避免配置中的重复端口

一个常见的错误是在 `config.yml` 文件的 `hostname` 字段中包含端口。
hostname 应该只包含 IP 地址或域名。它不应该包含端口。
这里是一个例子：

```yaml title="config.yml"
# ...
// highlight-red
hostname: "127.0.0.1:25565" // 错误的写法
// highlight-green
hostname: "127.0.0.1"       // 正确的写法
# ...
```

从 hostname 字段中移除端口可以解决与面板加载相关的问题。
