# 扩展故障排除

在使用 TypeWriter 扩展时遇到问题？本指南提供了逐步说明，以确保你的扩展设置正确并与 TypeWriter 插件正常运行。

## 正确的扩展放置位置

需要注意的是，TypeWriter 的扩展不是标准的 Paper 插件。它们是专门为 TypeWriter 设计的 JAR 文件，因此需要单独存储。为确保正常运行：

1. 导航到插件目录：`/plugins/Typewriter/extensions`。
2. 如果"extensions"文件夹不存在，请创建一个用于存储新扩展。
3. 将你的扩展文件放入这个"extensions"文件夹中。

这个专用文件夹确保 TypeWriter 可以正确读取和使用这些扩展，而不会与常规的 Paper 插件混淆。

## 扩展和插件版本兼容性

为了使 TypeWriter 插件和其扩展能够和谐运行，它们必须使用相同的版本。这一点在更新和降级时都很重要：

1. 更新 `typewriter.jar` 文件时，同时将所有扩展更新到相同版本。
2. 降级时也是同样的规则；确保插件和扩展都回退到匹配的版本。

保持 TypeWriter 插件和其扩展之间的版本一致性是防止兼容性问题和确保平稳运行的关键。
