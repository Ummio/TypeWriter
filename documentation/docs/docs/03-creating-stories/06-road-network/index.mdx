# 路径网络
:::info[开始之前]
本指南假设你已经安装了[Basic Extension](../../02-getting-started/01-installation.mdx#basic-extension)。\
同时,请确保你已经阅读了[布局](../../02-getting-started/02-layout.mdx)文档并创建了一个**静态**页面。
:::

路径网络对于让NPC在你的地图上移动或让玩家跟随路径来说是必不可少的。在本指南中,我们将向你展示如何创建路径网络以及如何在你的故事中使用它。

## 什么是路径网络?

路径网络是一个由节点和边组成的图形。节点是实体可以移动到的位置,边是连接这些位置的路径。

## 创建路径网络

要创建路径网络,你需要进入内容模式。在内容模式下,你可以使用物品栏中的物品来创建和编辑路径网络。

### 添加节点
你可以通过选择物品栏中的钻石并右键点击来添加节点。这将在你点击的位置创建一个新节点。

<Player url={require("../../assets/road-network/add-node.webm").default} />

### 连接节点
要连接节点,你需要选择物品栏中的线并右键点击两个节点。这将在这两个节点之间创建一条边。

<Player url={require("../../assets/road-network/connect-nodes.webm").default} />

### 删除节点和边
要删除节点或边,你需要选择物品栏中的剪刀并右键点击要删除的节点或边。

<Player url={require("../../assets/road-network/remove-node.webm").default} />

### 负节点
负节点是一种特殊类型的节点,它会阻止实体通过它。这对于创建单向路径或阻止实体通过某些区域很有用。

<Tabs>
  <TabItem value="with" label="使用负节点">
    <Player url={require("../../assets/road-network/negative-nodes-preview.webm").default} />
  </TabItem>
  <TabItem value="without" label="不使用负节点">
     <Player url={require("../../assets/road-network/non-negative-nodes-example.webm").default} />
  </TabItem>
</Tabs>

#### 如何添加负节点?
你可以通过选择物品栏中的下界合金锭并右键点击来添加负节点。
:::warning[重新计算]
在添加或删除负节点后,你必须使用物品栏中的红石重新计算边
:::

### 高亮节点
当你有很多节点时,可能很难看出哪些节点相互连接。为了使这更容易,你可以高亮显示相互连接的节点。要做到这一点,选择物品栏中的萤石并右键点击它。

## 结束
现在你已经学会了如何成功设置路径网络。
