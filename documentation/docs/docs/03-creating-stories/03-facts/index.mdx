# 事实

事实本质上是变量。它们存储可以被其他条目修改的信息。所有事实都是数字并被视为数字。

[`Basic Extension`](../../../adapters/BasicAdapter/BasicAdapter.mdx) 包含了许多可供使用的事实。但是需要注意的是,[`扩展`](../../../adapters/README.mdx)有能力进一步增加可用事实的数量。

## 为什么使用事实?

事实在动态内容创建和系统行为自定义中起着关键作用。以下是使用事实的一些原因:

- **动态任务:** 通过使用事实来存储和修改完成状态来跟踪玩家在任务中的进度。

- **自定义:** 通过利用事实来调整游戏内参数(如难度等级或角色属性)来个性化玩家体验。

- **互动叙事:** 通过使用事实来记住玩家的选择和行动,塑造不断发展的故事。

- **成就系统:** 通过使用事实来记录特定里程碑和成就来实现成就跟踪。

### 事实类型

事实有两种类型:可读和可写。

- **可读事实:** 用于条目的条件中。例如,检查玩家背包中是否有某个物品。
- **可写事实:** 用于修改器中修改事实的值。例如,更新玩家的任务进度。

:::info
有些事实既可读又可写。例如,[永久事实](../../../adapters/BasicAdapter/entries/fact/permanent_fact)可以在条件和修改器中使用。
但有些事实只能读取。例如,[物品数量事实](../../../adapters/BasicAdapter/entries/fact/inventory_item_count_fact)只能在条件中使用。
:::

## 组别

在事实中你可以选择一个组别。有3种类型的组别:

- **全局**: 为所有玩家设置事实。
- **世界**: 为特定世界中的所有玩家设置事实。
- **玩家**: 为特定玩家设置事实。

## 字段

在某些条目中,有些字段会影响事实的处理方式。

<Image img={require("../../assets/facts/criteria_and_modifier.png")} alt="条件和修改器字段" width={400} />

### 条件

条件是条目的条件,例如 `如果事实 = 10 那么...`。它控制条目是否会发生。

<Image img={require("../../assets/facts/criteria.png")} alt="条件字段" width={400} />

使用条件时,请按照以下步骤:

1. 选择要检查的事实。
2. 选择运算符。
3. 输入运算符要检查的值。

### 修改器

修改器顾名思义就是用来修改事实的。

<Image img={require("../../assets/facts/modifier.png")} alt="修改器字段" width={400} />

使用修改器时,请按照以下步骤:

1. 选择要修改的事实。
2. 选择运算符。你可以直接更改值(=)或添加到值(+)。
3. 输入运算符要修改的值。

:::warning
修改器只在条目执行时运行。
如果条目有条件且**其中一个条件**为`false`,那么条目不会被执行,事实也不会被修改。
:::

## 教程

为了帮助你开始使用事实,我们将使用永久事实来跟踪任务中的进度。

1. 创建一个新页面并选择为`static`。将其命名为`Playerprogress`
2. 点击 + 图标并选择`Add Permanent Fact`。将其重命名为`Playerprogress`并添加一个好的注释。
    <Image img={require("../../assets/facts/static-page.png")} alt="静态页面按钮" />
3. 选择玩家组别。
4. 在序列页面上,点击一个动作。
   - 设置**条件:** 检查 `Playerprogress` == 0。
   - 设置**修改器:** 如果条件满足,将 `Playerprogress` 更新为 1。
5. 创建额外的动作来表示不同的任务阶段,相应地修改 `Playerprogress`。

事实系统有很多可能性。以下是一些示例:

      **使用的事实:**
      - **可读事实:** [物品数量](../../../adapters/BasicAdapter/entries/fact/inventory_item_count_fact)

      1. 玩家与NPC对话。
      2. 使用物品数量事实检查条件,验证玩家是否有所需物品。

   </TabItem>
   <TabItem value="Progression Tracking" label="进度跟踪">
      **目标:** 跟踪玩家通过不同任务阶段的进度。

      **使用的事实:**
      - **可写事实:** [永久事实](../../../adapters/BasicAdapter/entries/fact/permanent_fact)

      **场景:**
      1. 玩家与NPC对话(进度设为1)。
      2. 完成特定动作(进度设为2)。
      3. 完成任务(进度设为3)。

   </TabItem>
   <TabItem value="Balance check" label="余额检查">
      **目标:** 查看玩家是否有足够的钱购买物品。

      **使用的事实:**
      - **可读事实:** [余额事实](../../../adapters/VaultAdapter/entries/fact/balance_fact.mdx)

      **场景:**
      1. 玩家与NPC对话。
      2. 使用余额事实检查条件,查看玩家是否有足够的余额。
      3. 如果玩家有足够的余额,他们可以购买物品。
      4. 如果玩家没有足够的余额,向玩家显示一条消息。

   </TabItem>
