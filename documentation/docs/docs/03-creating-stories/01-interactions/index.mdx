# 第一个互动

:::info[开始之前]
本指南假设你已经安装了[Basic Extension](../../02-getting-started/01-installation.mdx#basic-extension)。

同时,请确保你已经阅读了[布局](../../02-getting-started/02-layout.mdx)文档并创建了一个**序列**页面。
:::

让我们创建我们的第一个互动。我们的示例互动将包含以下步骤:

1. 玩家点击一朵花。
2. 打开一个聊天对话框。

如果在过程中需要任何帮助,请随时在我们的[Discord](https://discord.gg/HtbKyuDDBw)上寻求帮助。

## 什么是互动?

当玩家与某物互动并触发事件时就会发生互动。在本教程中,玩家点击花朵是互动,而打开的聊天对话框是被触发的事件。

## 创建互动

让我们从创建一个条目开始。点击面板右上角的 + 图标并搜索 `on interact with block`。通过点击 + 图标将其添加到你的页面。

<EntrySearch entryName='on_interact_with_block'/>

### 配置互动

在检查器中,将方块设置为 `Red Tulip`(红色郁金香)(1)并将名称设置为 `on flower click`(2)

<Image img={require("../../assets/interactions/on_flower_click.png")} alt="配置互动方块条目" width={400} />

## 创建事件

现在我们需要创建一个当玩家点击花朵时触发的事件。右键点击 `On Flower Click` 条目并点击 `+ link with ...` 打开搜索菜单。搜索 `Add Spoken` 并将其添加到页面。

<Player url={require("../../assets/interactions/add-spoken.webm").default} />

### 配置事件

在检查器中,将文本设置为 `Hello! I am a flower.` 并将持续时间设置为 `1s`。

### 配置说话者

按照以下步骤配置说话者:
1. 点击 `Select a speaker` 文本,在搜索菜单中点击 `Add Simple Speaker`。
2. 选择 `Add static` 并为该静态页面命名。
3. 点击简单说话者。
4. 在检查器中,将显示名称设置为 `A beautiful flower`。

<Player url={require("../../assets/interactions/simple-speaker.webm").default} />
