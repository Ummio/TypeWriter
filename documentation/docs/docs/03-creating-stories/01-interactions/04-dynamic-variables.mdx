# 随机对话
:::info[开始之前]
本教程基于[第一个互动](./index.mdx)教程。同时最好先阅读[事实](../03-facts/index.mdx)文档。
:::

在本教程中,你将学习如何使用动态变量并创建随机对话。

## 创建随机对话
首先,你需要打开从[第一个互动](./index.mdx)教程创建的对话的检查器。然后点击 Text 字段上方的 <ActionButton button='dynamic-variable'/> 并点击 `Add random Variable`。

<EntrySearch entryName='random_variable' />

这将在静态页面中创建一个随机变量。

## 配置随机变量
创建随机变量后,打开随机变量的检查器。在这里,你可以向随机变量添加多个值。现在,每次触发对话时,都会从该随机变量中显示一个不同的消息。\
对于本教程,我们选择添加以下几行,但这可以是任何你想要的内容:\
`Hello! I am a flower.`, `Wow, you found me.`, `Hey you!`\
你的动态变量现在应该看起来像这样:
<Image img={require("../../assets/interactions/random-variable.png")} alt="随机变量示例" width={400}/>

## 移除动态变量
要移除动态变量,只需点击动态变量旁边的 <ActionButton button='remove'/> 图标。

## 结果
现在,每次触发对话时,都会从随机变量中显示一个随机消息。
