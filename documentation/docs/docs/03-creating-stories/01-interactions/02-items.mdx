# 给予物品

:::info[开始之前]
建议先阅读[第一个交互](./index.mdx)再开始本教程。
:::

在本教程中,你将学习如何在交互中给予物品。

## 添加给予物品

要添加给予物品条目,请按照以下步骤操作:

1. 右键点击你的条目并选择`+ Link with ...`。
2. 搜索`Add give item`并点击+图标将其添加到你的序列中。

<EntrySearch entryName='give_item' />

## 配置给予物品

给予物品条目有两种给予物品的类型:自定义物品和序列化物品。

### 区别
<Tabs groupId="Differences" queryString>
  <TabItem value="custom-item" label="自定义物品" default>
    自定义物品允许你自定义物品的几乎所有方面。
    :::warning[NBT]
    自定义物品不能包含NBT数据。
    :::
    </TabItem>
    <TabItem value="serialized-item" label="序列化物品" default>
    序列化物品让你能够使用物品捕获器从游戏中捕获物品。
    :::warning[不可编辑]
    你不能编辑序列化物品。只能更改名称。
    :::
    </TabItem>
</Tabs>

### 使用物品捕获器(序列化物品)

使用物品捕获是最简单的方法,因为它只是将你当前在游戏中持有的物品复制到面板中。要做到这一点,只需点击`item`字段旁边的<ActionButton button='capture'/>图标。

<Player url={require("../../assets/interactions/item-capturer.webm").default} />

### 自行配置(自定义物品)

你也可以自己配置物品。在物品字段内选择`Custom Item`。点击`Components(0)`文本旁边的+图标来添加以下组件之一:
1. **Amount**: 给予玩家的物品数量。
2. **Flag**: 物品的特定选项。
3. **Lore**: 物品的说明文字。
4. **Material**: 这是玩家将获得的物品。
5. **Item Name**: 这是物品的名称。
