# 条件对话
:::info[开始之前]
建议先阅读[第一个交互](./index.mdx)和[事实系统](../03-facts/index.mdx)教程再开始本教程。
同时,确保你已经创建了一个**序列**页面。
:::

在本教程中,你将学习如何创建条件对话。这意味着如果玩家的某个事实值设置为特定值,就会显示相应的对话。

## 添加对话
首先我们需要添加一个对话。这可以通过学习[第一个交互](./index.mdx)教程来完成。

## 配置对话
在对话中,我们将文本字段设置为`嘿,这是你第一次点击我。`

### 设置条件
现在我们需要为对话配置条件。这可以通过点击检查器中条件字段旁边的+图标来完成。然后,你可以选择想要使用的事实。在本教程中,我们将使用一个名为`Flower Clicked`(花朵点击)的永久事实,并将组设置为玩家组。

<Image img={require("../../assets/interactions/flower-clicked-fact.png")} alt="花朵点击事实" width={400}/>

在条件内,将运算符设置为`==`,值设置为`0`。

### 配置修改器
你已经配置了条件,但现在我们需要修改事实,这样当你再次点击花朵时,会显示不同的对话。这可以通过点击检查器中修改器字段旁边的+图标来完成。然后,你可以选择想要修改的事实。在本教程中,我们将使用与条件相同的事实。在修改器内,将运算符设置为`=`,值设置为`1`。

<Image img={require("../../assets/interactions/add-spoken-fields.png")} alt="添加对话字段" width={400}/>

## 添加第二个对话
现在我们需要添加第二个对话。这可以通过右键点击`On Interact Block Event`条目并选择`+ Link with ...`来完成。然后,搜索`Add Spoken`并点击+图标将其添加到你的序列中。\
在文本字段中,我们将设置`哇,你又点击了我一次!`
你的序列页面应该看起来像这样:

<Image img={require("../../assets/interactions/conditional-dialogue-sequence.png")} alt="条件对话序列" width={400}/>

### 配置第二个对话的条件
现在我们需要为第二个对话配置条件。这可以通过点击检查器中条件字段旁边的+图标来完成。然后,选择`Flower Clicked`事实。在条件内,将运算符设置为`==`,值设置为`1`。

### 额外对话
要在点击花朵时添加更多对话或交互,设置另一个修改器,运算符为`=`,值为`2`(或任何其他值),然后重复前面的步骤。

## 结果
现在,当你第一次点击花朵时,将显示第一个对话。当你再次点击花朵时,将显示第二个对话。
