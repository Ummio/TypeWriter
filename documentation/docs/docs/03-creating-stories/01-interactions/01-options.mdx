# 添加选项

:::info[开始之前]
建议先阅读[第一个互动](./index.mdx)再开始本教程。
:::

在本教程中,你将学习如何在互动中创建和使用选项。

## 创建选项

要创建选项,请按照以下步骤操作:

1. 右键点击你的条目并选择 `+ Link with ...`。
2. 搜索 `Add Option` 并点击 + 图标将其添加到你的序列中。

<EntrySearch entryName='option' />

## 配置选项

让我们按照以下步骤配置选项:

1. 在 `Text` 字段中输入你想问玩家的问题,比如 `我是一朵漂亮的花吗?`。
2. 为选项选择正确的[说话者](./index.mdx#configuring-the-speaker)。

<Image img={require("../../assets/interactions/configure-option.png")} alt="配置选项条目" />

### 添加选项

1. 点击 `Options` 字段旁的 + 图标并展开 `Options #1`。
2. 在 `Text` 字段中输入选项1的回答,比如 `是的,你很漂亮!`。
3. 在 `Options #1` 内的 triggers 字段中点击 + 图标并展开 `Triggers #1`。
4. 点击 `Select a triggerable` 并在搜索菜单中创建你想在玩家选择该选项后触发的条目。比如一个内容为 `太好了,谢谢你!` 的对话。
5. 重复这些步骤来创建更多选项,比如 `不,你不漂亮。`。

<Image img={require("../../assets/interactions/adding-options.png")} alt="向选项条目添加选项" />
