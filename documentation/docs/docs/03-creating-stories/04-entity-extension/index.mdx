# 实体和NPC

:::danger[实体扩展]
在开始本教程之前,你必须先安装实体扩展。
:::

任何好的故事讲述都需要在世界中存在其他角色。Typewriter 有自己的实体扩展,允许你创建和控制实体,如NPC。

## 什么是实体扩展?
实体扩展是一个功能,它使在服务器上生成、管理和控制实体(如NPC)变得容易。

以下是一些功能:
- **定义实体**: 创建具有自定义数据的新实体并在世界中生成,可以在多个服务器中重复使用
- **条件显示实体**: 只在玩家处于特定任务阶段时显示NPC
- **活动**: 为实体添加自定义动作,比如在晚上走到酒馆或在城市中巡逻

## 创建NPC
Typewriter中的实体必须在`清单`页面中定义。
这是通过创建你想使用的实体类型的新定义来完成的。
这个定义可以使用实体实例多次生成。

**NPC**是一种特殊类型的实体,它是一个玩家,头上有名牌和指示器。
这使其易于使用,并且可能是你最常使用的实体类型。

### 创建新的NPC定义
要创建NPC定义,你必须创建一个清单页面并在其中定义NPC。以下是如何定义NPC的示例:

首先点击**添加页面**。
在下拉菜单中选择**清单**类型,并为页面命名。
在本例中,我们将其命名为`Characters`。

如果你需要更多关于如何创建页面的信息,请参见[布局](../../02-getting-started/02-layout.mdx)部分。

接下来,你必须定义NPC。点击`添加条目`按钮或右上角的`+`,
然后搜索`Add NPC Definition`,并将其添加到页面。你现在应该能在屏幕上看到该条目。

# 自定义实体
现在你已经定义了实体,你可以根据自己的喜好进行自定义。

## 设置实体名称
让我们将条目重命名为`Oliver Definition`。

要更改头顶上的显示名称,我们可以将`Display Name`字段更改为`<red><b>Oliver</b></red>`。

<Image img={require("../../assets/entity-extension/entity_name_change.png")} alt="重命名条目和实体" width={400} />

## 设置NPC的皮肤

要更改NPC的皮肤,我们可以更改`Skin`字段。
这需要一个材质和签名。
这些需要由Minecraft生成,不容易编辑。
幸运的是,Typewriter提供了一种从玩家uuid或url生成这些的方法。

让我们将oliver的皮肤更改为我在[NameMC](https://s.namemc.com/i/b2319359e305d7a2.png)上找到的这个
我们可以点击`Skin`字段右侧的链接图标来`从url获取`。

然后,我们可以输入url `https://s.namemc.com/i/b2319359e305d7a2.png` 并点击`获取`。

<Player url={require("../../assets/entity-extension/fetch_skin.webm").default} />

## 创建NPC实例
我们现在已经定义了NPC,但它还没有在世界中生成。
要生成实体,我们必须添加一个`实体实例`条目。
每种类型的实体都有不同的`实体实例`定义。
对于NPC,我们可以使用`NPC实例`定义。

<EntrySearch entryName='npc_instance'/>

首先,从`定义`下拉菜单中选择你想生成的NPC定义。
在这种情况下,我们将选择我们刚刚创建的`Oliver Definition`。
这将作为我们NPC实例的基础。

<Image img={require("../../assets/entity-extension/definition_select.png")} alt="选择定义" width={400} />

最后,我们需要设置NPC的生成位置。
这是当第一个玩家可能看到NPC时NPC将始终生成的位置。

我们可以使用内容模式选择器并获取你登录的Minecraft客户端的位置。

<Player url={require("../../assets/entity-extension/entity_location.webm").default} />

就是这样!
你现在已经创建了一个实体定义并在世界中生成了它的实例。
你现在可以在游戏中看到带有你提供的自定义名称、皮肤和数据的NPC了!

同样的原则适用于所有其他实体,如**牛**或**村民**。
你可以使用实体扩展定义和生成任何你想要的实体;只需确保你的定义类型与你想生成的实例类型匹配。

:::info
由于并非所有实体都有定义或实例,当你需要创建一个没有定义或实例的类型的实体时,请在[Discord](https://discord.gg/HtbKyuDDBw)上请求。
:::
