# 与实体互动
:::info[开始之前]
建议先阅读[实体和NPC](./index.mdx)再开始本教程。
:::

在本教程中,你将学习如何与实体互动。

## 添加实体互动事件
首先,我们需要添加 `Add On Entity Interact Event` 条目到我们的序列中。这可以通过点击面板右上角的 + 图标并搜索 `Add On Entity Interact Event` 来完成。通过点击 + 图标将其添加到你的页面。

<EntrySearch entryName="entity_interact_event"/>

### 选择定义
现在在 `New Entity Interact Event` 的检查器中的定义字段里,选择你想要互动的实体的定义。(对于本教程,这将是Oliver)

<Image img={require("../../assets/entity-extension/entity-interact-event-fields.png")} alt="实体互动事件字段" width={400} />

## 添加事件
现在我们需要添加一个当玩家与实体互动时触发的事件(对于本教程我们将使用对话)。右键点击 `New Entity Interact Event` 条目并点击 `+ link with ...` 打开搜索菜单。搜索 `Add Spoken` 并将其添加到页面。

<EntrySearch entryName="spoken"/>

将说话者设置为oliver定义,文本字段设置为 `你好,我是Oliver。`。
