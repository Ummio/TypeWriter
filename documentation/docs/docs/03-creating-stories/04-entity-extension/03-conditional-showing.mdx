# 条件显示NPC
:::warning[NPC创建]
本教程假设你已经创建了一个实体。\
如果你还没有创建,请先阅读[实体扩展教程](./index.mdx)。
:::
在本教程中,你将学习如何使用受众条目来有条件地显示实体。

## 添加受众条目
有很多不同类型的受众条目可用。对于本教程,我们将使用游戏时间受众,但所有其他类型都有类似的功能。

首先,点击面板右上角的 + 图标并搜索 `New Game Time Audience`。通过点击 + 图标将其添加到你的页面。

<EntrySearch entryName="game_time_audience"/>

## 将其添加到你的实体实例上
现在按住你的实体实例并将其拖到 `New Game Time Audience` 条目上。这将把受众链接到实体。

现在应该看起来像这样:

<EntryDisplay pages={[
    require("./assets/conditional/manifest.json"),
]} />

## 配置受众
在受众条目内,有2个字段:
* **Children**: 这里你可以添加当满足受众条件时应该显示的实体。
* **Active Times**: 这将使受众的Children只在满足此条件时显示。
* **Inverted**: 这将反转受众,意味着实体只在不满足受众条件时显示。
