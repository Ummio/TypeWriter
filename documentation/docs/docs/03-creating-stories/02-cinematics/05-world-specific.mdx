# 世界特定的电影场景
:::info[开始之前]
建议先阅读[电影场景](./index.mdx)再开始本教程。
:::

在本教程中,你将学习如何创建世界特定的电影场景。此功能允许你创建一个可以在多个世界中使用的电影场景。

## 创建动态变量
首先我们需要创建一个动态变量。这个变量将用于确定玩家所在的世界。请按照以下步骤操作:
1. 进入你的摄像机电影场景并点击一个片段
2. 在片段内的其中一个路径点上点击 <ActionButton button='dynamic-variable'/> 图标。
3. 搜索 `Player World Position Variable` 并点击它以添加到你的片段。

<EntrySearch entryName='player_world_position_variable'/>

### 配置动态变量
:::warning[重复]
对摄像机电影场景片段内的所有路径点重复此步骤。
:::
现在在**摄像机电影场景片段**的检查器中,你可以设置电影场景的坐标。
<Image img={require("../../assets/cinematics/world-specific-player-variable.png")} alt="配置动态变量" width={400} />
#### 世界值在哪里?
好问题,世界值不见了是因为我们正在使用 `Player World Position Variable` 来确定世界。\
玩家所在的世界将是使用的世界。
