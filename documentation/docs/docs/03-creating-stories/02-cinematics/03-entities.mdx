# 电影场景中的实体

:::info[开始之前]
建议先阅读[电影场景](./index.mdx)再开始本教程。
:::

在本教程中,你将学习如何在电影场景中添加实体。

## 添加实体电影场景

首先,我们需要添加一个实体电影场景条目。点击面板右上角的 + 图标并搜索 `Add Entity Cinematic`。通过点击 + 图标将其添加到你的页面。

<EntrySearch entryName='entity_cinematic'/>

### 配置实体电影场景

在检查器中,你需要配置以下字段:
* **持续时间**: 这是实体电影场景的总持续时间(以刻度为单位)。
* **实体**: 这是将在电影场景中移动的实体。你可以从下拉菜单中选择一个实体。
* **路径**: 这是实体将要遵循的路径。

让我们将持续时间设置为 `100` (5秒)。

### 添加路径点

现在我们需要添加实体将要遵循的路径点。点击 `Add Path` 按钮添加一个新的路径点。

你可以通过以下方式添加路径点:
1. 使用内容模式选择器获取你当前的位置
2. 手动输入坐标

<Player url={require("../../assets/cinematics/add-entity-path.webm").default} />

### 添加更多路径点

让我们再添加一些路径点来创建一个更有趣的实体移动。

<Player url={require("../../assets/cinematics/add-more-entity-paths.webm").default} />

## 结果

现在,当电影场景播放时,实体将沿着你定义的路径移动。

<Player url={require("../../assets/cinematics/entity-cinematic-result.webm").default}/>

:::tip
你可以添加多个实体电影场景条目来让多个实体同时移动。
:::
