# 电影场景

:::info[开始之前]
本指南假设你已经安装了[Basic Extension](../../02-getting-started/01-installation.mdx#basic-extension)。

同时,请确保你已经阅读了[布局](../../02-getting-started/02-layout.mdx)文档并创建了一个**电影场景**页面。
:::

在本教程中,你将学习如何创建电影场景。电影场景是一系列定时的动作,可以用来创建引人入胜的故事情节。

## 什么是电影场景?

电影场景是一系列定时的动作,可以用来创建引人入胜的故事情节。它们可以包含多个不同类型的动作,如:
- 摄像机移动
- 对话
- 实体移动
- 音效
- 标题
- 粒子效果

## 创建电影场景

让我们从创建一个简单的电影场景开始。点击面板右上角的 + 图标并搜索 `Add Camera Cinematic`。通过点击 + 图标将其添加到你的页面。

<EntrySearch entryName='camera_cinematic'/>

### 配置电影场景

在检查器中,你可以看到以下字段:
- **持续时间**: 电影场景的总持续时间(以刻度为单位,20刻度 = 1秒)
- **路径**: 摄像机将要遵循的路径

让我们将持续时间设置为 `100` (5秒)。

### 添加路径点

现在我们需要添加摄像机将要遵循的路径点。点击 `Add Path` 按钮添加一个新的路径点。

你可以通过以下方式添加路径点:
1. 使用内容模式选择器获取你当前的位置
2. 手动输入坐标

<Player url={require("../../assets/cinematics/add-path.webm").default} />

### 添加更多路径点

让我们再添加一些路径点来创建一个更有趣的摄像机移动。

<Player url={require("../../assets/cinematics/add-more-paths.webm").default} />

## 触发电影场景

现在我们已经创建了电影场景,我们需要一种方法来触发它。让我们创建一个序列页面并添加一个互动来触发电影场景。

1. 创建一个新的序列页面
2. 添加一个 `On Interact With Block` 条目
3. 添加一个 `Add Cinematic` 条目并将其链接到互动
4. 在 `Add Cinematic` 条目中选择我们刚刚创建的电影场景

<Player url={require("../../assets/cinematics/add-cinematic-trigger.webm").default} />
