# 电影场景中的对话

:::info[开始之前]
建议先阅读[电影场景](./index.mdx)再开始本教程。
:::

在本教程中,你将学习如何在电影场景中添加对话。

## 添加对话

首先,我们需要添加一个动作栏对话条目。点击面板右上角的 + 图标并搜索 `Add Action Bar Dialogue`。通过点击 + 图标将其添加到你的页面。

<EntrySearch entryName='action_bar_dialogue'/>

### 配置对话

在检查器中,你需要配置以下字段:
* **文本**: 这是将显示在动作栏中的文本。
* **开始帧**: 这是对话开始显示的帧。
* **结束帧**: 这是对话停止显示的帧。

<Image img={require("../../assets/cinematics/action-bar-dialogue.png")} alt="配置动作栏对话" width={400} />

## 结果

现在,当电影场景播放时,对话将在指定的帧范围内显示在动作栏中。

<Player url={require("../../assets/cinematics/action-bar-dialogue-result.webm").default}/>

## 其他对话类型

除了动作栏对话外,还有其他类型的对话可以在电影场景中使用:
* **聊天对话**: 在聊天栏中显示对话。
* **标题对话**: 在屏幕中央显示大标题。
* **副标题对话**: 在屏幕中央显示小标题。

这些对话类型的配置方式与动作栏对话相同。
