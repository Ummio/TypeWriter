# 可跳过的电影场景
:::info[开始之前]
建议先阅读[电影场景](./index.mdx)再开始本教程。
:::
在本教程中,你将学习如何允许玩家跳过电影场景的某些部分。

## 添加可跳过的电影场景
首先点击面板右上角的 + 图标并搜索 `Add Skippable Cinematic`。通过点击 + 图标将其添加到你的页面。

<EntrySearch entryName='skip_cinematic'/>

### 配置可跳过的电影场景
在跳过电影场景的检查器中,你可以在确认键字段中选择 `SNEAK` 或 `SWAP_HANDS`。这个键将是玩家需要按下以跳过电影场景的按键。本指南将使用 SNEAK 键来跳过电影场景。

## 添加可跳过部分
现在在可跳过电影场景的检查器中,你可以通过点击操作部分的 `Add segment` 文本来添加一个新片段。这将创建一个新片段。
在开始帧和结束帧字段中,你可以设置玩家可以跳过电影场景的时间。对于本指南,这将是 0 和 100。

## 结果
现在你有了一个可跳过的电影场景,可以通过按下你在确认键字段中设置的键来跳过。
