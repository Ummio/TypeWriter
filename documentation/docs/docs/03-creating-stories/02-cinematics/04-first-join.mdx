# 首次加入电影场景

:::info[开始之前]
在开始之前,建议阅读以下部分:[互动](../01-interactions/index.mdx)、[电影场景](./index.mdx)和[事实](../03-facts/index.mdx)。确保你已经创建了一个序列页面和一个电影场景页面。
:::

在本教程中,你将学习如何创建一个只在玩家首次加入服务器时播放的电影场景。

## 创建序列

首先,我们需要创建一个序列页面。在序列页面中,点击面板右上角的 + 图标并搜索 `New On Player Join`。通过点击 + 图标将其添加到你的页面。

<EntrySearch entryName='on_player_join'/>

### 配置序列

在检查器中,你需要配置以下字段:
* **事实**: 这是用来检查玩家是否已经看过电影场景的事实。
* **值**: 这是事实必须等于的值才能触发电影场景。

<Image img={require("../../assets/cinematics/add-cinematic-fields.png")} alt="add-cinematic-fields" width={400} />

## 添加 `Add Cinematic` 条目
现在我们需要将 `Add Cinematic` 条目添加到我们的序列中。这可以通过右键点击 `New On Player Join` 条目并选择 `+ Link with ...` 来完成。然后,搜索 `Add Cinematic` 并点击 + 图标将其添加到你的序列中。现在你的序列页面应该看起来像这样:

<Image img={require("../../assets/cinematics/add-cinematic.png")} alt="Add-Cinematic" width={400} />

在 `New Cinematic` 内,通过检查器在页面字段中选择你想触发的电影场景。对于本教程,我们将使用 `Tutorial_Cin` 电影场景。

## 结果
现在,当玩家首次加入服务器时,电影场景将会播放。当玩家再次加入时,电影场景将不会播放。
