# 收集任务
:::danger[任务扩展]
在开始本教程之前,你必须先安装任务扩展。
:::
:::info[开始之前]
建议先阅读[任务系统](./index.mdx)再开始本教程。
:::

在本教程中,你将学习如何创建一个收集任务。这种类型的任务要求玩家收集特定数量的物品。

## 创建任务

首先,我们需要创建一个清单页面并添加一个任务条目。

<EntrySearch entryName="quest"/>

### 配置任务
在任务条目内,我们需要配置以下字段:
- **显示名称**: 这是任务的名称,玩家将看到这个名称。
- **激活条件**: 这些条件必须满足才能激活任务。
- **完成条件**: 这些条件必须满足才能完成任务。

对于本教程,我们将创建一个要求玩家收集64个石头的任务。

<EntryNodeInspector entryId="7FTmTrqbWsq7wSj" pages={manifestPages} />

### 添加目标
现在我们需要添加一个目标来显示玩家需要收集多少石头。

<EntryNodeInspector entryId="7FTmTrqbWsq7wSj" pages={manifestPages} />

### 清单结果
现在你的页面应该看起来像这样:
<EntryDisplay pages={manifestPages} />

## 触发任务
要开始任务有很多选项。对于本指南,我们将通过对话来开始任务,但这可以是任何你想要的方式。请在你的序列页面中添加一个对话条目。

<EntrySearch entryName="spoken"/>

#### 配置对话
在对话内请按如下方式配置字段:

<EntryNodeInspector entryId="7FTmTrqbWsq7wSj" pages={sequencePages} />

**请注意** 在这个对话中使用的修改器会让玩家追踪任务,因为我们正在改变任务事实的值。当你改变任务事实的值时,这种情况总是会发生。

### 序列结果
现在你的页面应该看起来像这样:
<EntryDisplay pages={sequencePages} />
