在某些任务中,目标需要根据玩家的状态前进和后退。
例如,玩家需要在特定区域内才能继续。

## 添加目标

对于我们的任务,我们想要根据玩家是否装备了磁力靴来改变目标。

由于目标是 `受众` 条目,我们可以使用各种 `受众` 条目来显示和隐藏目标。

为了扩展我们的任务,我们将有以下目标:

- 当玩家还没有找到磁力靴时,目标是__找到一种方法穿过峡谷__。
- 当玩家找到了磁力靴时,目标是__装备磁力靴__。
- 当玩家装备了磁力靴时,目标是__走过峡谷__。
