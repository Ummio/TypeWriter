# 显示任务
:::danger[任务扩展]
在开始本教程之前,你必须先安装任务扩展。
:::
现在我们已经创建了任务,我们想要向玩家显示它。
首先,我们需要追踪任务。

## 任务追踪

追踪任务是为了向玩家显示任务进度。
其他条目可以使用被追踪的任务来向玩家显示信息。

:::warning 重要
虽然同时可以有多个任务处于激活状态,但一次只能**追踪**一个任务。
:::

你可以使用 `/tw quest track <quest_id>` 命令手动追踪任务。
或者使用[追踪任务动作](../../../adapters/BasicAdapter/entries/action/track_quest.mdx)条目。

此外,当任务变为激活状态时,Typewriter 会自动追踪任务。
或者当一个目标变为激活状态且优先级高于当前追踪的任务时。

## PlaceholderAPI

如果你安装了 [PlaceholderAPI](../../05-helpful-features/03-placeholderapi.mdx),你可以使用以下占位符:

| 占位符 | 描述 |
| ----------- | ----------- |
| `%typewriter_tracked_quest%` | 被追踪任务的名称。 |
| `%typewriter_tracked_objectives%` | 被追踪任务的目标列表,用逗号分隔。 |

## 侧边栏

如果 Typewriter 正在管理你的侧边栏,你可以使用[目标行条目](../../../adapters/BasicAdapter/entries/quest/objective_lines.mdx)来显示被追踪任务的目标。
