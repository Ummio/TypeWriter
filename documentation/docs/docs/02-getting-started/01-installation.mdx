# 安装指南

:::danger[平台兼容性]
TypeWriter 仅适用于 **Paper** 服务器。它不支持 Spigot 或 Bukkit 服务器。
:::

## 安装 TypeWriter 插件

请按照以下步骤在你的 Paper Minecraft 服务器上安装 TypeWriter 插件:

### 插件安装

1. 首先下载 <DownloadVersion />。
2. 将下载的插件放入服务器的 `plugins` 文件夹中。

### 处理依赖项

TypeWriter 需要安装其他插件才能正常运行。

3. 下载并将 TypeWriter 的依赖项 [PacketEvents](https://modrinth.com/plugin/packetevents/versions?l=paper) 添加到你的 `plugins` 目录中。

4. 确保你**没有**安装 [InteractiveChat](https://www.spigotmc.org/resources/interactivechat-show-items-inventory-in-chat-custom-chat-keywords-bungee-velocity-support.75870/) 或 [CustomNamePlates](https://polymart.org/resource/customnameplates.2543) 插件，因为它们可能与 TypeWriter 产生冲突。

### 基础扩展

TypeWriter 提供了多种扩展用于自定义，但必须安装 `BasicExtension`。

5. 从 <DownloadVersion /> 下载最新的 `BasicExtension` 并将其添加到 `plugins/TypeWriter/extensions` 文件夹中。

有关可用扩展的完整列表，请参阅[扩展部分](../../adapters)。

6. 所有组件就位后，重启你的 Minecraft 服务器以完成 TypeWriter 的安装。

:::danger[版本不同步]
更新插件时，**必须**安装与该更新对应的扩展。如果扩展和插件的版本不匹配，可能导致插件无法正常运行！
:::

## 配置网页面板

:::caution[外部服务器提供商]
Typewriter 的网页面板与某些外部服务器提供商**不兼容**，包括 **Minehut**、**Aternos** 和 **Apex**。这些提供商通常不支持多个端口，不过你可以向他们的支持团队请求开放额外的端口。

如果无法实现，你仍然可以使用 Typewriter 的其他功能，或考虑搭建一个安装了 Typewriter 的本地服务器。

如需进一步帮助，欢迎在我们的 [Discord](https://discord.gg/HtbKyuDDBw) 上提问。
:::

:::info[资源消耗]
请注意，网页面板和网络套接字会消耗服务器的宝贵资源，建议将面板部署在开发服务器上，而不是生产服务器上。
:::

现在我们已经安装了插件，需要配置网页面板。

网页面板需要开放两个端口。这些端口可以更改，但至少需要两个新的开放端口。默认端口是 `8080` 和 `9092`。

要启用网页面板，请按照以下步骤操作：

### 启用网页面板

1. 打开 `plugins/Typewriter/config.yml` 文件。
2. 将设置更改为以下内容：

```yaml title="plugins/Typewriter/config.yml"
# 是否启用网页面板和网络套接字
enabled: true
# 服务器的主机名。将此更改为你服务器的 IP。
hostname: "127.0.0.1"
# 面板使用网络套接字来同步服务器的更改，并允许多人同时工作。
websocket:
  # 网络套接字服务器的端口。确保此端口已开放。
  port: 9092
  # 使用的身份验证方式。如果你不知道这是做什么的，请保持不变。
  auth: "session"
panel:
  # 可以在套接字仍然开放的情况下禁用面板。仅在你知道自己在做什么时才禁用。
  # 如果网络套接字被禁用，则面板也将始终被禁用。
  enabled: true
  # 网页面板的端口。确保此端口已开放。
  port: 8080
```

3. 请使用 [portchecker](https://portchecker.co/) 检查你的端口是否开放。如果没有开放，请自行开放端口或联系你的主机提供商。
4. 重启服务器以完成安装。

## 连接到网页面板

要连接到网页面板，请按照以下步骤操作：

1. 在游戏中运行 `/typewriter connect` 命令。这将提供一个访问网页面板的链接。

![连接命令](../assets/installation/connect-command.gif)

2. 在你喜欢的网页浏览器中打开链接。

<Image img={require("../assets/installation/connect-book.png")} width={400} alt="在书中连接到网页面板" />

成功连接后，你可以使用网页面板来创建和配置任务、NPC 对话等。面板还允许你查看和编辑服务器现有的玩家交互。
