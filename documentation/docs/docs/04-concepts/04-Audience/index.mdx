# 受众条目

受众条目是一种特殊类型的[清单条目](./Manifest),用于有条件地向一组玩家显示内容。
玩家可以在条目的受众中。
换句话说,受众条目的内容将显示给其受众中的玩家。

受众条目有两种类型:

### 受众显示条目

受众显示用于向一组玩家显示内容。
可以是诸如:应用药水效果,或显示Boss血条等内容。

### 受众过滤条目

受众过滤条目有一个子条目列表,可以包含受众条目和受众过滤条目。
它们用作过滤受众显示条目受众的一种方式。

受众过滤器可以:

#### 过滤玩家
过滤自身及其子条目的受众。比如`标准受众`,只有满足标准的玩家才能进入受众。

#### 显示内容
像普通的受众显示条目一样显示内容,但使用子条目作为显示内容。就像`侧边栏`使用`行`条目那样。


# 过滤是如何工作的?

当玩家加入服务器时,他们会被添加到所有根受众条目中。
根受众条目是没有父条目的条目。

如上所示,任何没有父条目的条目都是根条目。
过滤器仍然可以允许或拒绝玩家进入它们自己的受众。
但是,如果没有链接,它们不会影响其他条目的受众。

## 链接

我们可以将过滤器链接在一起以创建更复杂的过滤器。
现在玩家只有在同时满足两个条件时才会在`显示`中。

## 多个父条目

当一个条目有多个父条目时,如果任何一个父条目允许玩家进入受众,玩家就会在该条目的受众中。
