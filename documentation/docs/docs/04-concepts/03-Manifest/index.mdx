# 清单条目

清单条目是在[清单页面](../02-Pages/02-manifest.mdx)中定义的条目。
它们用于定义可以在多个[序列页面](../02-Pages/01-sequence.mdx)中重复使用的内容。

## 清单条目的类型

清单条目有两种主要类型:

### 定义条目

定义条目用于定义可以在序列页面中使用的内容。
例如,NPC定义条目定义了NPC的外观和行为。

### 实例条目

实例条目用于在游戏世界中放置定义条目。
例如,NPC实例条目在游戏世界中放置一个NPC定义。

## 定义和实例的关系

定义和实例之间的关系如下:

<RiveBoard stateMachines="State Machine 1" artboard="Definition Instance" aspectRatio={500/300} src={require('./assets/manifest_entries.riv').default} />

如上所示:
- 定义条目定义了内容的外观和行为
- 实例条目在游戏世界中放置定义条目
- 一个定义可以有多个实例
- 一个实例只能有一个定义

## 定义和实例的示例

以下是一些定义和实例的示例:

| 定义 | 实例 | 描述 |
|------------|-----------|-------------|
| NPC定义 | NPC实例 | 定义NPC的外观和行为,实例在世界中放置NPC |
| 任务定义 | 任务实例 | 定义任务的目标和奖励,实例在世界中放置任务 |
| 对话定义 | 对话实例 | 定义对话的内容和选项,实例在世界中放置对话 |

## 为什么使用定义和实例?

使用定义和实例有以下好处:
- 可以在多个地方重复使用相同的内容
- 更容易管理和修改内容
- 减少重复工作
- 保持内容的一致性
