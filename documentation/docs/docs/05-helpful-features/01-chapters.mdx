# 章节

章节为你的 TypeWriter 工作流程增添了便利性，类似于书本中章节的熟悉结构。就像电脑中文件形成文件夹一样，TypeWriter 的章节系统将页面组织在章节中。

### 设置章节
创建章节非常简单，只需右键点击一个页面并选择`更改章节`。输入想要的章节名称，然后点击`更改`即可。
<Player url={require("../assets/chapters/chapters.webm").default} />

### 设置子章节
创建子章节也非常简单。只需使用主章节名称并添加一个`.`，例如，`hello.test` 将生成一个子章节。如下所示：

<Image img={require("../assets/chapters/sub-chapters.png")} alt="子章节" width={400} />

你可以根据需要添加任意多的子章节来扩展故事。例如，`hello.test.morning` 也是可以的。TypeWriter 会自动收集具有相同章节名称的页面并将它们组合在一起。
