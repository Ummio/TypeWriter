# PlaceholderAPI

:::warning[需要插件]
要使用本教程,你必须安装 [PlaceHolderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) 插件。
:::

## 使用 PlaceholderAPI 的占位符

Typewriter 提供了一些可以在服务器上使用的占位符。这些占位符可以用于显示事实的值或其他信息。

### 事实占位符

要显示一个事实的值,你可以使用以下格式:
```
%typewriter_<entry id>%
```

例如,如果你有一个ID为 `money` 的事实,你可以使用 `%typewriter_money%` 来显示它的值。

#### 时间戳
对于时间戳事实,你可以使用以下占位符:
- `%typewriter_<entry id>:time:lastUpdated%`: 显示事实最后更新的时间。
- `%typewriter_<entry id>:time:lastUpdated:relative%`: 显示距离事实最后更新的时间,例如 `3分20秒`。

#### 可过期的事实

对于可过期的事实,你可以使用以下占位符:
- `%typewriter_<entry id>:time:expires%`: 显示事实过期的时间。
- `%typewriter_<entry id>:time:expires:relative%`: 显示距离事实过期的时间,例如 `3分20秒`。

## 自定义占位符
Typewriter 还有2个自定义占位符,它们是:

- `%typewriter_tracked_quest%`: 显示当前追踪的任务的显示名称。
- `%typewriter_tracked_objectives%`: 显示当前追踪的任务的激活目标的显示名称。
