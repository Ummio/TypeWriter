# 什么是代码片段？

代码片段是扩展可以使用的小段信息。主要与内容如何显示给用户有关。
代码片段允许你自定义不同适配器的各个部分。例如，你可以自定义`基础扩展`中消息的显示方式。

# 如何自定义代码片段？
代码片段可以通过编辑 `plugin/Typewriter/snippets.yml` 文件来自定义。

:::info 重要提示
请注意，代码片段仅在首次使用时才会被写入。因此，如果你想要自定义某个代码片段，你需要先触发使用该代码片段的条目。
:::

例如，对于`基础扩展`，当第一个人收到`消息对话条目`后，`snippets.yml` 文件会是这样的：

```yaml title="plugin/Typewriter/snippets.yml"
dialogue:
  message:
    format: |2

      <gray> | <bold><speaker></bold><reset><gray> |
      <reset><white> <message>
```

然后你可以编辑这个文件来自定义代码片段。比如，如果你想要更改说话者名字的默认颜色，你可以将 `<bold><speaker></bold>` 改为 `<bold><red><speaker></red></bold>`。

Yaml 使用 `|` 来表示文本是多行字符串。

```yaml title="plugin/Typewriter/snippets.yml"
dialogue:
  message:
    // highlight-next-line
    format: |2

      <gray> | <bold><speaker></bold><reset><gray> |
      <reset><white> <message>
```

`|2` 表示这是一个多行字符串，并且在字符串末尾有 `2` 个换行符。如果你不想要这些换行符，可以删除 `2` 使其变为 `|`。
