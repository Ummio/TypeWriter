# 快捷键
本页面包含使用 TypeWriter 时可以使用的键盘快捷键列表。\
首先请选择你的操作系统：

<Tabs groupId="operating-systems">
  <TabItem value="windows" label="Windows">
| 快捷键                                                   | 描述                                                                                    |
| ----------------------------------------------------------| ---------------------------------------------------------------------------------------- |
| `ctrl + k `或` ctrl + space`                              | 打开搜索框                                                                               |
| `tab `或` ctrl + n`                                       | 下一项                                                                                   |
| `shift + tab  `或` ctrl +  p`                             | 上一项                                                                                   |
| `ctrl + shift + p`                                        | 发布页面                                                                                 |
  </TabItem>
  <TabItem value="mac" label="macOS">
| 快捷键                                                   | 描述                                                                                    |
| ----------------------------------------------------------| ---------------------------------------------------------------------------------------- |
| `⌘ + k `或` ⌘ + space`                                  | 打开搜索框                                                                               |
| `tab `或` ⌘ + n`                                         | 下一项                                                                                   |
| `shift + tab  `或` ⌘ +  p`                               | 上一项                                                                                   |
| `⌘ + shift + p`                                          | 发布页面                                                                                 |
  </TabItem>
</Tabs>

## 搜索
在搜索菜单中也有一些快捷键。

| 快捷键                                                   | 描述                                                                                    |
| ----------------------------------------------------------| ---------------------------------------------------------------------------------------- |
| `!ae` 或 `!ne`                                            | 仅显示**新建**条目                                                                       |
| `!ee `或` !a`                                             | 仅显示**现有**条目                                                                       |

在搜索菜单中按 Tab 键可以轻松浏览所有条目。底部还会显示一个操作菜单，包括：`+添加`或`打开维基`等选项。
