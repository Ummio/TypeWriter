# 什么是 Typewriter？

Typewriter 是一个插件，允许你在服务器上创建和管理玩家互动。它可以让你创建任务、NPC 对话等内容。它还允许你管理服务器上现有的玩家互动。

在本 wiki 中有几个页面将帮助你开始使用 Typewriter。第一个页面是[安装指南](./02-getting-started/01-installation.mdx)。这个页面将帮助你安装 Typewriter 和 `BasicExtension`。
然后你可以按照[第一个互动](./03-creating-stories/01-interactions/index.mdx)指南来创建你的第一个互动。

:::caution[测试版]
Typewriter 目前处于测试阶段。这意味着该插件仍在开发中，可能包含错误。如果你发现任何错误，请在我们的 [Discord](https://discord.gg/HtbKyuDDBw) 中报告。
:::
