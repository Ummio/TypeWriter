# 创建扩展
## 简介
Typewriter 是一个动态平台，支持扩展开发，这些扩展是用于增强整体功能的模块化组件。
扩展是独立的、易于共享的，并且能够无缝集成到 TypeWriter 系统中。
它们允许你创建自定义条目并在网页面板中显示。
本指南旨在指导你完成创建扩展的过程。

## 前置要求
 - Java 开发工具包 (JDK) 21 或更高版本
 - 集成开发环境 (IDE)，如 IntelliJ IDEA 或 Eclipse
 - 对 Gradle 和 Spigot API 的基本了解

## 设置 Gradle 项目
首先为你的 Typewriter 扩展建立一个 Gradle 项目。以下是 Gradle 项目的完整设置：

<Tabs>
    <TabItem value="release" label="正式版" default>
        在你的 `settings.gradle.kts` 文件中添加以下内容：
        ```kotlin title="settings.gradle.kts" showLineNumbers
        pluginManagement {
            repositories {
                mavenCentral()
                gradlePluginPortal()
                maven("https://maven.typewritermc.com/releases")
            }
        }
        ```

        在你的 `build.gradle.kts` 文件中添加以下内容：
        ```kotlin title="build.gradle.kts" showLineNumbers
        import com.github.jengelman.gradle.plugins.shadow.tasks.ShadowJar

        plugins {
            kotlin("jvm") version "2.0.21"
            id("com.typewritermc.module-plugin") version "<模块插件版本>"
        }

        // 替换为你自己的信息
        group = "me.你的用户名"
        version = "0.0.1"

        typewriter {
            namespace = "<你所有扩展发布所用的公司名称>"

            extension {
                name = "<扩展名称>"
                shortDescription = "<简短描述>"
                description = "<详细描述>"
                engineVersion = "<最新的 typewriter 版本>"

                paper {
                    // 可选 - 如果你想确保某个插件必须安装才能使用此扩展
                    dependency("<插件名称>")
                }
            }
        }

        kotlin {
            jvmToolchain(21)
        }
        ```
    </TabItem>
    <TabItem value="beta" label="测试版">
        在你的 `settings.gradle.kts` 文件中添加以下内容：
        ```kotlin title="settings.gradle.kts" showLineNumbers
        pluginManagement {
            repositories {
                mavenCentral()
                gradlePluginPortal()
                maven("https://maven.typewritermc.com/beta")
            }
        }
        ```

        在你的 `build.gradle.kts` 文件中添加以下内容：
        ```kotlin title="build.gradle.kts" showLineNumbers
        import com.github.jengelman.gradle.plugins.shadow.tasks.ShadowJar

        plugins {
            kotlin("jvm") version "2.0.21"
            id("com.typewritermc.module-plugin") version "<模块插件版本>"
        }
        
        typewriter {
            namespace = "<你所有扩展发布所用的公司名称>"

            extension {
                name = "<扩展名称>"
                shortDescription = "<简短描述>"
                description = "<详细描述>"
                engineVersion = "<最新的 typewriter 版本>"
                channel = com.typewritermc.moduleplugin.ReleaseChannel.BETA

                paper {
                    // 可选 - 如果你想确保某个插件必须安装才能使用此扩展
                    dependency("<插件名称>")
                }
            }
        }

        kotlin {
            jvmToolchain(21)
        }
        ```
    </TabItem>
</Tabs>

:::info 替换你的信息
请确保将诸如 `me.你的用户名` 之类的占位符替换为你的项目详细信息。
:::

## 构建扩展
创建扩展类后，构建扩展。这可以通过运行 `build` Gradle 任务来完成。
这将在 `build/libs` 目录中生成一个 JAR 文件。
这个 JAR 文件可以作为 TypeWriter 中的扩展使用。
将 JAR 文件放在 `plugins/TypeWriter/extensions` 目录中。
Typewriter 将自动加载并运行扩展。

:::tip 重新加载扩展
你可以重启 Minecraft 服务器或使用 `/typewriter reload` 命令来重新加载扩展。
:::


如果出现任何问题，请检查控制台是否有错误信息，并确保扩展配置正确。
如果需要帮助，请加入 [Discord 服务器](https://discord.gg/HtbKyuDDBw) 寻求帮助。
