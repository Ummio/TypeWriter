# 触发条目

在 `TriggerEntry` 中有多种简单的方法来触发所有后续条目。
最重要的是你需要一个 `player`（玩家）来触发这些条目。

:::info
Typewriter 会自动处理只触发应该被触发的条目。
如果条件不满足，条目将不会被触发。
:::

你期望当玩家再次点击 NPC 时，会触发下一段对话。

## 自定义触发器
Typewriter 基于 `EventTrigger` 接口进行触发。
所以所有被触发的条目都被包装在 `EntryTrigger` 中。
