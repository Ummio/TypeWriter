# 0.8.X 版本的所有 API 变更

API 有很多变化。
在更新扩展之前，请务必阅读这些变更。

## `build.gradle.kts` 变更

现在引擎版本不再在单独的 `engine` 块中指定，而是在 `extension` 块中指定。

## `Initializable` 变更

注册 `Initializable` 的方式已更改。

```kotlin showLineNumbers
// highlight-red
@Initializer
// highlight-green
@Singleton
object ExampleInitializer : Initializable {
    override suspend fun initialize() {
        // 当扩展初始化时执行某些操作
    }

    override suspend fun shutdown() {
        // 当扩展关闭时执行某些操作
    }
}

```

## 触发条目变更

由于 Typewriter 现在有了 `InteractionContext`，在触发条目时需要传递这个参数。
由于变化很多，请查看[触发条目](../triggering)页面了解更多信息。

```kotlin showLineNumbers
val entries: List<TriggerableEntry> = ...

// highlight-red
entries triggerAllFor player
// highlight-green
entries.triggerAllFor(player, context())
```

## ActionEntry 变更

由于 `ActionEntry` 现在需要 `InteractionContext`，`execute` 函数的签名已更改。

```kotlin showLineNumbers
@Entry("example_action", "一个示例动作条目", Colors.RED, "material-symbols:touch-app-rounded")
class ExampleActionEntry(
    override val id: String = "",
    override val name: String = "",
    override val criteria: List<Criteria> = emptyList(),
    override val modifiers: List<Modifier> = emptyList(),
    override val triggers: List<Ref<TriggerableEntry>> = emptyList(),
) : ActionEntry {
    // highlight-red-start
    override fun execute(player: Player) {
        super.execute(player) // 这将应用所有修改器
    // highlight-red-end
    // highlight-green-start
    override fun ActionTrigger.execute() {
        // 现在会自动应用所有修改器
    // highlight-green-end
        // 对玩家执行某些操作
    }
}
```

## 移除 `CustomTriggeringActionEntry`

由于动作条目现在可以自己指定 Typewriter 应如何处理触发：

```kotlin showLineNumbers
@Entry("example_action", "一个示例动作条目", Colors.RED, "material-symbols:touch-app-rounded")
class ExampleCustomTriggeringActionEntry(
    override val id: String = "",
    override val name: String = "",
    override val criteria: List<Criteria> = emptyList(),
    override val modifiers: List<Modifier> = emptyList(),
// highlight-red-start
    @SerializedName("triggers")
    override val customTriggers: List<Ref<TriggerableEntry>> = emptyList(),
) : CustomTriggeringActionEntry {
    override fun execute(player: Player) {
        super.execute(player) // 这将应用修改器
        // 对玩家执行某些操作
        player.triggerCustomTriggers() // 可以稍后调用来触发下一个条目
    // highlight-red-end
// highlight-green-start
    override val triggers: List<Ref<TriggerableEntry>> = emptyList(),
) : ActionEntry {
 override fun ActionTrigger.execute() {
        // 这将禁用 Typewriter 自动触发下一个条目，
        // 并禁用自动应用修改器
        disableAutomaticTriggering()

        // 现在你可以手动触发下一个条目
        triggerManually()

        // 或者如果你想指定要触发哪些触发器，也可以这样做
        triggers.filterIndexed { index, _ -> index % 2 == 0 }.triggerFor(player)

        // 你也可以手动应用修改器
        applyModifiers()
        // highlight-green-end
    }
}
```

## 对话信使变更

由于这是 Typewriter 中唯一需要使用注解注册的地方，我们改变了它，允许 DialogueEntry 指定它使用的信使。
此外，我们现在需要将 `context` 参数转发给信使。

```kotlin showLineNumbers
@Entry("example_dialogue", "一个示例对话条目", Colors.BLUE, "material-symbols:chat-rounded")
class ExampleDialogueEntry(
    override val id: String = "",
    override val name: String = "",
    override val criteria: List<Criteria> = emptyList(),
    override val modifiers: List<Modifier> = emptyList(),
    override val triggers: List<Ref<TriggerableEntry>> = emptyList(),
    override val speaker: Ref<SpeakerEntry> = emptyRef(),
    @MultiLine
    @Placeholder
    @Colored
    @Help("显示给玩家的文本")
    val text: String = "",
) : DialogueEntry {
    // highlight-green-start
    // 可以返回 null 以跳过对话
    override fun messenger(player: Player, context: InteractionContext): DialogueMessenger<*>? {
        // 你可以使用 if 语句根据不同条件返回不同的信使
        return ExampleDialogueDialogueMessenger(player, context, this)
    }
    // highlight-green-end
}

// highlight-red-start
@Messenger(ExampleDialogueEntry::class)
class ExampleDialogueDialogueMessenger(player: Player, entry: ExampleDialogueEntry) :
    DialogueMessenger<ExampleDialogueEntry>(player, entry) {

    companion object : MessengerFilter {
        override fun filter(player: Player, entry: DialogueEntry): Boolean = true
    }
    // highlight-red-end
// highlight-green-start
class ExampleDialogueDialogueMessenger(player: Player, context: InteractionContext, entry: ExampleDialogueEntry) :
    DialogueMessenger<ExampleDialogueEntry>(player, context, entry) {
// highlight-green-end


    // 每个游戏刻（每秒20次）调用。
    // cycle 参数从0开始，每刻递增。
    override fun tick(context: TickContext) {
        super.tick(context)
        if (state != MessengerState.RUNNING) return

        player.sendMessage("${entry.speakerDisplayName}: ${entry.text}".parsePlaceholders(player).asMini())

        // 当我们想要结束对话时，可以将状态设置为 FINISHED
        state = MessengerState.FINISHED
    }
}
```
