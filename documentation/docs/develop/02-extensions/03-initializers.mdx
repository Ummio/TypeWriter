# 初始化器

有时你的扩展在使用前需要进行一些初始化操作。
例如，你可能需要为插件添加一个钩子，以使其能够与你的扩展一起工作。

## 声明初始化器
要声明一个初始化器，你需要创建一个实现了 `Initializable` 接口的**对象**。
并在类上添加 `@Initializer` 注解。

<CodeSnippet tag="initializer" json={require("../snippets.json")} />

:::danger 确保清理
当扩展被卸载时会调用 `shutdown` 方法。
你应该确保在扩展卸载时没有资源泄漏。
:::

当扩展被加载和卸载时，Typewriter 会自动注册并调用这些控制流方法。
