# 开发
Typewriter 有不同的组成部分可供开发。

- **扩展：** 这些是可以轻松共享和添加到系统中的独立构建模块。
- **插件：** 这些是 Typewriter 工作原理的核心部分。我们欢迎所有帮助，但请先讨论，因为这些更改可能会影响许多用户。
- **用户界面：** 这是用 Flutter 编写的，是 Typewriter 最复杂的部分。这也是最有趣的开发部分，因为你可以直观地看到你的工作成果。

文档的这部分仍在建设中。如果你想提供帮助，请通过 [Discord](https://discord.gg/HtbKyuDDBw) 联系我们。
